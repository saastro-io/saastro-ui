# Welcome to SaastroCMS!

This is your first blog post. You can edit this content directly from the admin panel at `/admin`.

## Getting Started

1. **Visit the Admin Panel** - Go to `/admin` to access the content management interface
2. **Create New Posts** - Click "New Entry" to create a new blog post
3. **Use Visual Editor** - Add `?__saastrocms_visual=true` to any page URL to edit inline

## Features

- **Git-based Content** - All your content is stored in Git for version control
- **Visual Editing** - Edit content directly on the page with live preview
- **Media Management** - Upload and manage images easily
- **Markdown Support** - Write in Markdown with full formatting support
